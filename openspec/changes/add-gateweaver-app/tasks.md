## 2. ARP 帧编解码与注入引擎（arp-gateway-takeover）

- [x] 2.1 实现以太网+ARP 帧编解码器（构造 reply/who-has、解析 opcode/spa/tpa/发送 MAC），验证：单元测试覆盖编解码往返与畸形帧拒绝
- [ ] 2.2 实现 AF_PACKET 收发原语：绑定指定接口、按目标单播发送、捕获 `who-has <gwIP>`，验证：在 veth/bridge 网络命名空间测试台上用 `tcpdump` 确认帧收发正确
- [x] 2.3 实现每目标注入循环（周期重申，默认 20s，可配）+ 令牌桶限速（默认 ≤2 帧/秒/目标），验证：单测断言速率与"白名单外零发包"
- [x] 2.4 实现被动应答循环：白名单目标查询网关 IP 时毫秒级应答 fnOS MAC，白名单外的查询不响应，验证：测试台上模拟目标 `arping <gw>` 抓到应答且延迟达标
- [x] 2.5 实现网关真实 MAC 探测与缓存（D4），及恢复通告（单播真实映射，立即+1s 双发），验证：移除目标后测试台抓到正确恢复帧且停止注入
- [x] 2.6 实现每目标接管生效判定（观测目标→网关方向流量是否到达本机）与状态机（未启用/注入中/已生效/未见流量），验证：测试台两种场景（应答/静默）分别落入正确状态
