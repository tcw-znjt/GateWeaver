# Spec Delta

## Purpose

定义 GateWeaver 的 Web 管理台与其 REST API 行为：局域网设备发现、目标与模式配置管理、运行状态与事件日志查看、一键恢复；访问边界限定于局域网且需鉴权。

## ADDED Requirements

### Requirement: 受限的局域网访问边界
管理台 SHALL 仅监听 LAN 侧接口地址（默认端口可配置），不提供 WAN 侧入口；除健康检查外的全部 API 与页面 SHALL 要求会话鉴权。首次启动时若未设置口令，系统 SHALL 强制引导设置或以仅本机可用的引导凭据方式初始化。

#### Scenario: 未鉴权访问被拒
- **WHEN** 局域网内主机未登录直接请求配置 API
- **THEN** 服务 SHALL 返回 401，且不泄露任何配置内容

#### Scenario: WAN 侧不可达
- **WHEN** 管理台运行中
- **THEN** 从 fnOS 的非 LAN 接口（如存在的外部管理口/VPN 段外的接口）SHALL 无法建立到管理端口的连接（默认策略）

### Requirement: 局域网设备发现
系统 SHALL 提供当前接管接口上的邻居设备列表（IP、MAC、主机名（可得时）、近期活跃度），数据来源 SHALL 包括本机 ARP 邻居表与按需的主动探测；列表 SHALL 支持勾选后一键添加为接管目标。

#### Scenario: 发现并添加目标
- **WHEN** 用户在发现列表中选择一台设备并点击"设为目标"
- **THEN** 该设备以 MAC 为主键进入目标列表并可立即启用接管

### Requirement: 配置管理
管理台 SHALL 支持以下配置的查看与修改并即时热生效：目标增删与单独启停、上游网关（自动/手动）、转发送达模式、注入重申间隔、监听端口、上游故障自动放开开关。配置 SHALL 持久化，守护进程重启后保持一致。

#### Scenario: 热生效
- **WHEN** 用户修改注入间隔并保存
- **THEN** 引擎在不重启服务的情况下按新间隔执行，且重启进程后新值仍在

#### Scenario: 非法输入拒绝
- **WHEN** 用户提交非法的目标 IP 格式或与网关相同的地址
- **THEN** API SHALL 返回校验错误，配置不变更

### Requirement: 状态总览与事件日志
管理台 SHALL 展示：全局开关状态、上游网关及其可达性、每个目标的接管状态（未启用/注入中/已生效/未见流量）与流量计数（包数/字节数），以及带时间戳的事件日志（接管建立、恢复、上游故障、配置变更、错误）。日志 SHALL 有容量上限并滚动。

#### Scenario: 接管状态一目了然
- **WHEN** 存在 3 个目标，分别处于未启用、注入中、已生效状态
- **THEN** 控制台对每个目标显示其对应状态与最近一次注入时间

### Requirement: 一键恢复
管理台 SHALL 提供"全部恢复"操作：立即撤销所有目标的接管并恢复网络原状，但保留目标配置（禁用态），以便随后一键重新启用。

#### Scenario: 紧急恢复
- **WHEN** 用户点击"全部恢复"
- **THEN** 所有目标在秒级收到恢复通告，全局开关置为关闭，配置保留
