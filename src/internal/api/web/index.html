使用边界声明

GateWeaver 通过 ARP 通告使 指定 局域网设备的默认网关指向本机（旁路由）。 您确认并承诺：仅对 您拥有或已获明确授权管理 的网络与设备使用该功能； 对他人网络设备使用 ARP 欺骗在多数司法辖区违法。

建议：接管期间保留"一键恢复"入口；上游故障时应用会自动放开。
